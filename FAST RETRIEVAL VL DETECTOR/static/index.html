VisionLabel AI — User Guide

Workflow Overview

  1. Load Images: Drag & drop $N$ images into the left dropzone, or click Load Sample Pack to experiment with pre-bundled scenarios.
  2. Define Target Prompts: Type queried objects in the right panel (e.g. dog, car, traffic light). The system caches prompt embeddings in <1ms.
  3. Run Auto-Annotation: Click Annotate All N Images to autonomously detect and annotate all loaded images.
  4. Review & Adjust: Use the canvas to inspect bounding boxes, adjust the Similarity slider to filter sensitivity, or manually draw/delete boxes.
  5. Export: Download standard COCO 1.0, YOLO format ZIP, or Rendered Annotated Images.
